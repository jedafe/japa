# Control App Rework - Bits UI + 100% API Consumption

## Goal

Rework the Control App frontend from the ground up using Bits UI components (Tabs, Select, Switch, Toggle, DatePicker, Tooltip, Dialog, etc.), consume 100% of the backend API, and take inspiration from Dev.to Admin Panel's clean, tabbed, card-based layout.

## Key Decisions

- **Theme**: Switch to Bits UI CSS variable system (`--background`, `--foreground`, `--muted`, `--border-input`, etc.) from the docs. Rewrite `app.css`.
- **Tabs**: Use Tabs everywhere possible - even single-section pages get tab layouts for consistency.
- **Cache**: Add full cache stats display with namespace tables consuming `/control/cache/stats`.

---

## Phase 0: Foundation - app.css + Shared Components

### 0A. Rewrite `app.css` with Bits UI theme

Replace the current CSS variable system with the Bits UI theme from the docs. This is the foundation everything else builds on.

**File**: `src/app.css`

Key changes:
- Replace `--color-primary`, `--color-border`, `--color-surface`, etc. with `--background`, `--foreground`, `--muted`, `--muted-foreground`, `--border`, `--border-input`, `--accent`, `--accent-foreground`, `--destructive`, `--shadow-*`, etc.
- Add `@theme inline` block mapping CSS vars to Tailwind colors
- Add `@plugin "tailwindcss-animate"` for Bits UI animations
- Add custom variant `@custom-variant dark (&:is(.dark *))`
- Add keyframe animations: `accordion-down`, `accordion-up`, `fade-in`, `fade-out`, `scale-in`, `scale-out`, etc.
- Define radius tokens: `--radius-card`, `--radius-input`, `--radius-button`, etc.
- Font: Keep Inter as primary, add a display font for headings
