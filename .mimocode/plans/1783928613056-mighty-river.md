# Plan: Add Missing Frontend Consumers for Unconsumed API Routes

## Context

The backend defines ~450+ API routes. After a thorough audit, 8 routes have complete backend implementations but no frontend consumer. The user wants to wire up the frontend to consume these existing routes.

**Note:** The initial audit flagged ~30 routes as unconsumed, but deeper analysis revealed many ARE consumed through direct `api()` calls in Svelte pages. Only 8 routes are truly unconsumed.

## Implementation Steps

### Step 1: Admin API Client — Add Missing Functions

**File:** `apps/admin/src/lib/api.ts`

Add API functions for routes that don't have them:

```ts
// Save page as template
async savePageAsTemplate(pageId: string, name: string) {
  return api<{ id: string }>(`/admin/pages/${pageId}/save-as-template`, {
    method: 'POST',
    body: JSON.stringify({ name }),
  });
}

// Validate SEO
async validateSeo(id: string) {
  return api<{ issues: string[] }>(`/admin/seo/validate/${id}`);
}

// Set field permissions
async setFieldPermission(fieldId: string, params: { user_group_id: string; can_view: boolean; can_edit: boolean }) {
  return api<void>(`/custom-fields/${fieldId}/permissions`, {
    method: 'PUT',
    body: JSON.stringify(params),
  });
}

// List all affiliate links (admin)
async listAffiliateLinksAdmin(page = 1, pageSize = 20) {
  return api<{ links: any[]; total: number }>(`/admin/affiliate-links?page=${page}&page_size=${pageSize}`);
}
```

Also add `listCoupons` and `getProgramInfo` to the **main app API client** (`apps/main/src/lib/api.ts`).
