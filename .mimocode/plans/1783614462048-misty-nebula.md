# Fix: Remove 2 CODE_ONLY media admin routes

## Problem

The route diff shows 2 CODE_ONLY routes:
```
DELETE /admin/media/:x
GET    /admin/media
```

These routes exist in the code but are **NOT in the catalog**. The catalog only has quarantine-related admin media routes:
- `GET /admin/media/quarantined`
- `POST /admin/media/:id/approve`
- `POST /admin/media/:id/reject`

## Root Cause

The plan's Task 9 said to add `GET /admin/media` and `DELETE /admin/media/:id`, but the catalog doesn't include these routes. Per the global constraints:

> "Catalog path + param names are authoritative"

The catalog is the source of truth, not the plan. These routes were added based on the plan's Task 9, but the catalog doesn't include them.

## Solution

Remove the 2 CODE_ONLY routes from `internal/server/server.go`:

1. `GET /admin/media` — remove the route at line ~1003
2. `DELETE /admin/media/:id` — remove the route at line ~1005

- `internal/server/server.go` — remove 2 route registrations
