## Phase 1: Critical Fixes (AUDIT-BE-001, AUDIT-BE-002)

### 1.1 — Soft-Delete for contents Table (AUDIT-BE-001)

**Problem:** `DELETE FROM contents` permanently destroys user data, violating Rule 11.

**Files to modify:**
- `migrations/000127_contents_soft_delete.up.sql` (NEW) — add `deleted_at` column + partial index
- `internal/db/queries/contents.sql` — change `DeleteContent` to UPDATE, add `deleted_at IS NULL` filter to all SELECT queries
- `internal/admin/moderation.go:841,853` — add `tenant_id` scoping to RemoveContent/RestoreContent

**Migration SQL:**
```sql
ALTER TABLE contents ADD COLUMN deleted_at timestamptz;
CREATE INDEX idx_contents_soft_delete ON contents(tenant_id, id) WHERE deleted_at IS NULL;
```

**Query changes in contents.sql:**
- Line 124: Change `DELETE FROM contents` to `UPDATE contents SET deleted_at = now(), updated_at = now() WHERE id = @id AND tenant_id = @tenant_id AND deleted_at IS NULL`
- Add `AND c.deleted_at IS NULL` to: `ListContentsByTenant`, `ListContentsByType`, `ListContentsBySpace`, `GetContentByID`, `GetContentBySlug`, `ListContentByTag`

**Moderation fixes (moderation.go):**
- Line 841: Add `AND tenant_id = $2` to RemoveContent UPDATE
- Line 853: Add `AND tenant_id = $2` to RestoreContent UPDATE

-- name: CreateModerationAction :exec

-- name: AddUserGroupMembership :exec
INSERT INTO user_group_memberships (user_id, group_id, granted_by) VALUES ($1, $2, $3) ON CONFLICT DO NOTHING;

SELECT a.*, u.username FROM moderation_appeals a JOIN users u ON a.user_id = u.id WHERE a.tenant_id = $1 AND ($2::text = '' OR a.status = $2) ORDER BY a.created_at DESC;

-- name: GetModerationAppeal :one
SELECT * FROM moderation_appeals WHERE id = $1 AND tenant_id = $2;

-- name: UpdateAppealStatus :exec
UPDATE moderation_appeals SET status = $1, reviewed_by = $2, reviewed_at = now(), review_note = $3 WHERE id = $4 AND tenant_id = $5;

-- name: UpdateContentReportStatus :exec

-- name: DeleteAdminBroadcast :exec
