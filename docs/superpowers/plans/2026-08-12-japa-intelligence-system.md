# JapaConnect Intelligence System Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the intelligence ingestion spine (source registry, fetcher adapters, raw documents, change detection, AI extraction with per-field confidence/evidence, dedup, publish gate), scholarships as the first domain projection, and the Japa Radar user surface (main site page + dashboard widget + notifications) — all reusing existing JapaConnect infrastructure (§20 AI gateway, §11 Asynq, §13 Meilisearch, §69 RAG, §35 notifications, §31 follow, §14 content).

**Architecture:** Domain-agnostic spine in a new `internal/intelligence/` package with 11 sub-packages. Generic `intel_sources` / `intel_raw_documents` / `intel_records` tables feed a thin domain projection table (`scholarships`) via a per-domain promoter on publish. Domain events flow through a `DomainEventPublisher` interface (Asynq-backed in v1, Kafka-swap-ready). Internal task orchestration stays direct Asynq enqueue. Editorial overrides on `scholarships.editorial_overrides` ensure human edits win on re-crawl.

**Tech Stack:** Go 1.26.4 (module `github.com/jedafe/japa`), chi router, sqlc + pgx/v5, Postgres 18, Asynq + Valkey/Redis, Meilisearch, pgvector, SvelteKit 2 + Svelte 5 + Bits UI + Tailwind v4 (frontends), bun (frontend tooling only — Rule 18). New Go deps: `github.com/PuerkitoBio/goquery`, `github.com/ledongthuc/pdf`. New system deps: `tesseract-ocr`, `poppler-utils`.

## Global Constraints

These apply to every task. Each task's requirements implicitly include this section.

- **Module path:** `github.com/jedafe/japa`

# ADR-112: Dedicated `scholarships` table for intelligence system projection

**Status:** Proposed
**Date:** 2026-08-12
**Reverses:** §73 "no parallel data store" locked decision
**Spec:** docs/superpowers/specs/2026-08-12-japa-intelligence-system-design.md

## Context

Section 73 (Scholarship Finder, ADR-073) locked the decision that all
scholarship data lives in `custom_field_values` — "no parallel data store."
The Intelligence System (spec linked above) needs to store machine-extracted
fields with per-field confidence, per-field source evidence, provenance
linkage to a source registry, freshness/verification status, and editorial
overrides. The `custom_field_values` EAV store cannot carry this shape of
data:

- No place for per-field `{value, confidence, evidence}` triples
- No FK to a `intel_sources` row
- No freshness/verification status independent of editorial content
- Structured queries (`eligible_countries @> '{NGA}' AND deadline > now()`)
  become multi-join EAV queries instead of single-table filters with GIN
  indexes

## Decision

Introduce a dedicated `scholarships` table that *references* `contents(id)`
via `guide_id` (the §14 editorial wrapper). The `contents` row remains the
editorial wrapper (title, body, SEO, comments, RAG indexing, feed fan-out).
The `scholarships` row holds only the machine-extracted structured fields +
provenance + confidence + freshness + editorial overrides.

This is the exact pattern §73 already uses for `saved_scholarships.guide_id
→ contents(id)` — just "extracted by ingestion" instead of "saved by user."

`saved_scholarships.guide_id → contents(id)` continues to work unchanged.

## Consequences

- Reverses §73's "no parallel data store" wording. The §73 section file is
  updated to reference the new `scholarships` table.
- Existing scholarship guide content (in `custom_field_values`) is backfilled
  into `scholarships` rows by migration 430 (one-time, reversible).
- `scholarships.intel_record_id` is nullable to support backfilled rows that
  predate the ingestion system (`override_source='editorial'`).
- Structured queries on scholarships become single-table with GIN indexes.
- Editorial overrides (`scholarships.editorial_overrides`) let admins correct
  AI-extracted fields without the next crawl reverting them.

## Alternatives considered

1. **Keep §73 as-is, ingestion writes to `custom_field_values`** — provenance
   and confidence live in a separate `intel_records` table, synced to
   `custom_field_values` on publish. Rejected: hidden coupling between two
   stores, awkward structured queries, no clean editorial-override path.

2. **Dedicated `scholarships` table that IS the content (no `contents` row)**
   — Rejected: scholarships lose comments, feed fan-out, RAG indexing, SEO,
   TipTap body. They become second-class citizens.

3. **`intel_records` as source of truth, `scholarships` as materialized view**
   — Rejected: materialized view refresh is operationally painful, editorial
   overrides become awkward (can't write to a view).
```

-- 000428_intelligence_spine_tables.up.sql
-- Intelligence System spine: source registry, raw documents, extraction records, review log.
-- Ref: docs/superpowers/specs/2026-08-12-japa-intelligence-system-design.md (Section 3)

BEGIN;

CREATE TABLE intel_sources (
  id                   uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  name                 text NOT NULL,
  domain               text NOT NULL,
  source_url           text NOT NULL,
  category             text NOT NULL,
  source_type          text NOT NULL,
  trust_level          smallint NOT NULL,
  crawl_method         text NOT NULL,
  crawl_frequency      text NOT NULL,
  crawl_frequency_mins int NOT NULL DEFAULT 1440,
  robots_policy        jsonb NOT NULL DEFAULT '{}',
  source_license       text,
  attribution_required boolean NOT NULL DEFAULT true,
  usage_restriction    text,
  provider_config      jsonb NOT NULL DEFAULT '{}',
  enabled              boolean NOT NULL DEFAULT true,
  last_crawled_at      timestamptz,
  last_success_at      timestamptz,
  last_error_at        timestamptz,
  last_error_message   text,
  last_changed_at      timestamptz,
  consecutive_failures int NOT NULL DEFAULT 0,
  created_at           timestamptz NOT NULL DEFAULT now(),
  updated_at           timestamptz NOT NULL DEFAULT now()
);

CREATE UNIQUE INDEX idx_intel_sources_url        ON intel_sources (source_url);
CREATE INDEX idx_intel_sources_enabled_freq      ON intel_sources (enabled, crawl_frequency_mins) WHERE enabled;
CREATE INDEX idx_intel_sources_category          ON intel_sources (category, trust_level);

CREATE TABLE intel_raw_documents (
  id            uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  source_id     uuid NOT NULL REFERENCES intel_sources(id) ON DELETE CASCADE,
  url           text NOT NULL,
  http_status   int NOT NULL,
  http_headers  jsonb NOT NULL DEFAULT '{}',
  content_type  text,
  body          bytea NOT NULL,
  content_hash  text NOT NULL,
  retrieved_at  timestamptz NOT NULL DEFAULT now()
);

CREATE INDEX idx_intel_raw_docs_source ON intel_raw_documents (source_id, retrieved_at DESC);
CREATE INDEX idx_intel_raw_docs_hash    ON intel_raw_documents (source_id, content_hash);

CREATE TABLE intel_records (
  id                  uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  source_id           uuid NOT NULL REFERENCES intel_sources(id) ON DELETE CASCADE,
  raw_document_id     uuid NOT NULL REFERENCES intel_raw_documents(id) ON DELETE CASCADE,
  entity_type         text NOT NULL,
  external_key        text NOT NULL,
  extracted           jsonb NOT NULL,
  confidence          jsonb NOT NULL,
  evidence            jsonb NOT NULL,
  confidence_overall  real NOT NULL,
  status              text NOT NULL DEFAULT 'extracted'
                        CHECK (status IN ('extracted','deduped','auto_published','review_required','approved','rejected','published','stale')),
  freshness_score     int NOT NULL DEFAULT 100,
  geo_space_ids       uuid[] NOT NULL DEFAULT '{}',
  extracted_at        timestamptz NOT NULL DEFAULT now(),
  last_verified_at    timestamptz NOT NULL DEFAULT now(),
  promoted_record_id  uuid,
  UNIQUE(source_id, external_key)
);

    Headers     map[string]string

    Body        []byte
    ContentHash string

// NormalizeForHash produces a stable hash key from raw bytes.
// Strips scripts/styles and collapses whitespace for HTML; for other
// content types, hashes the raw bytes.

    h := sha256.Sum256(normalizeBody(body, contentType))
    return hex.EncodeToString(h[:])
}

    if strings.Contains(contentType, "text/html") {
        // TODO in Task 15 (static adapter): use goquery to strip scripts/styles
        // For now, collapse whitespace as a baseline.
        return []byte(strings.Join(strings.Fields(string(body)), " "))

    "context"
    "errors"
    "fmt"
    "time"

    "github.com/redis/go-redis/v9"
    "github.com/jedafe/japa/internal/intelligence/sources"

var (
    ErrRobotsDisallowed  = errors.New("fetcher: robots.txt disallows this path")
    ErrRateLimited       = errors.New("fetcher: rate limited for this domain")
    ErrLicenseRepublish  = errors.New("fetcher: source license forbids republish")
    ErrCrawlLocked       = errors.New("fetcher: source already being crawled")
)

// PreflightChecker enforces robots.txt, rate-limit, license, and crawl-lock
// rules before any adapter runs.
type PreflightChecker struct {
    rdb             *redis.Client
    crawlLockTTLSecs int
    rateLimitPerMin  int
}

func NewPreflightChecker(rdb *redis.Client, crawlLockTTLSecs, rateLimitPerMin int) *PreflightChecker {
    return &PreflightChecker{rdb: rdb, crawlLockTTLSecs: crawlLockTTLSecs, rateLimitPerMin: rateLimitPerMin}
}

// Check runs all pre-flight checks. Returns nil if all pass.
// Crawl lock is SET NX EX — if the source is already being crawled, returns ErrCrawlLocked.
func (p *PreflightChecker) Check(ctx context.Context, source sources.Source) error {
    // 1. Crawl lock
    lockKey := fmt.Sprintf("jc:intel:crawllock:%s", source.ID)
    locked, err := p.rdb.SetNX(ctx, lockKey, "1", time.Duration(p.crawlLockTTLSecs)*time.Second).Result()
    if err != nil {
        return fmt.Errorf("fetcher: crawl lock: %w", err)
    }
    if !locked {
        return ErrCrawlLocked
    }

    // 2. License check (for Tier 3+, source_license must be non-NULL and not 'proprietary' for republish)
    if source.TrustLevel >= 3 {
        if source.SourceLicense == nil || *source.SourceLicense == "proprietary" {
            return ErrLicenseRepublish
        }
    }

    // 3. Rate limit (token bucket per domain — simplified: check a counter)
    rateKey := fmt.Sprintf("jc:intel:ratelimit:%s", source.Domain)
    count, err := p.rdb.Incr(ctx, rateKey).Result()
    if err != nil {
        return fmt.Errorf("fetcher: rate limit: %w", err)
    }
    if count == 1 {
        p.rdb.Expire(ctx, rateKey, time.Minute)
    }
    if count > int64(p.rateLimitPerMin) {
        return ErrRateLimited
    }

    // 4. Robots.txt check (load from cache or fetch in Task 15)
    // For now, if robots_policy has allowed=false, refuse.
    // Full robots.txt fetching + parsing is implemented in the static adapter task.

    return nil
}

// ReleaseCrawlLock removes the crawl lock. Called after fetch completes
// (success or failure) to allow immediate retry if needed.
func (p *PreflightChecker) ReleaseCrawlLock(ctx context.Context, sourceID string) {
    p.rdb.Del(ctx, fmt.Sprintf("jc:intel:crawllock:%s", sourceID))
}

package fetcher

import (
    "context"
    "fmt"
    "io"
    "net/http"
    "strings"
    "time"

    "github.com/PuerkitoBio/goquery"

    "github.com/jedafe/japa/internal/intelligence/sources"
)

type StaticFetcher struct {
    client *http.Client
}

func NewStaticFetcher() *StaticFetcher {
    return &StaticFetcher{client: &http.Client{Timeout: 30 * time.Second}}
}

func (f *StaticFetcher) Fetch(ctx context.Context, source sources.Source) (FetchResult, error) {
    req, err := http.NewRequestWithContext(ctx, "GET", source.SourceURL, nil)
    if err != nil {
        return FetchResult{}, fmt.Errorf("static: new request: %w", err)
    }
    req.Header.Set("User-Agent", "JapaConnect-Intelligence/1.0 (+https://japa.to)")

    resp, err := f.client.Do(req)
    if err != nil {
        return FetchResult{}, fmt.Errorf("static: do: %w", err)
    }
    defer resp.Body.Close()

    body, err := io.ReadAll(resp.Body)
    if err != nil {
        return FetchResult{}, fmt.Errorf("static: read body: %w", err)
    }

    contentType := resp.Header.Get("Content-Type")
    normalized := normalizeHTML(body)
    hash := NormalizeForHash(normalized, contentType)

    return FetchResult{
        HTTPStatus:  resp.StatusCode,
        Headers:     flattenHeaders(resp.Header),
        ContentType: contentType,
        Body:        body,
        ContentHash: hash,
    }, nil
}

func normalizeHTML(body []byte) []byte {
    doc, err := goquery.NewDocumentFromReader(strings.NewReader(string(body)))
    if err != nil {
        return body
    }
    doc.Find("script, style, noscript").Remove()
    text := doc.Text()
    return []byte(strings.Join(strings.Fields(text), " "))
}

func flattenHeaders(h http.Header) map[string]string {
    out := make(map[string]string, len(h))
    for k, v := range h {
        if len(v) > 0 {
            out[k] = v[0]
        }
    }
    return out
}

}

    Title       string `xml:"title"`
    Link        string `xml:"link"`
    Description string `xml:"description"`
    PubDate     string `xml:"pubDate"`
}

func (f *RSSFetcher) Fetch(ctx context.Context, source sources.Source) (FetchResult, error) {

    if err := xml.Unmarshal(body, &feed); err != nil {

        Headers:     flattenHeaders(resp.Header),
        ContentType: contentType,
        Body:        body,
        ContentHash: NormalizeForHash(body, contentType),

}

    if err := xml.Unmarshal(body, &feed); err != nil {

    "github.com/ledongthuc/pdf"

type PDFFetcher struct {
    ocrFallback *OCRFetcher
}

func NewPDFFetcher(ocr *OCRFetcher) *PDFFetcher {
    return &PDFFetcher{ocrFallback: ocr}
}

// ExtractText pulls text from a PDF body. Falls back to OCR if extraction
// returns empty/minimal text (scanned PDFs).
func (f *PDFFetcher) ExtractText(body []byte) (string, error) {
    r, err := pdf.NewReader(bytes.NewReader(body), int64(len(body)))
    if err != nil {
        return "", fmt.Errorf("pdf: new reader: %w", err)
    }
    var b strings.Builder
    totalPage := r.NumPage()
    for i := 1; i <= totalPage; i++ {
        page := r.Page(i)
        if page.V.IsNull() {
            continue
        }
        text, err := page.GetPlainText(nil)
        if err != nil {
            continue
        }
        b.WriteString(text)
    }
    text := b.String()
    if len(strings.TrimSpace(text)) < 50 && f.ocrFallback != nil {
        return f.ocrFallback.ExtractText(body)
    }
    return text, nil
}

// Package changedetector compares content hashes to determine if a source
// has changed since the last crawl.
package changedetector

type Decision int

const (
    DecisionChanged   Decision = iota // proceed to extraction
    DecisionUnchanged                  // skip extraction, update last_crawled_at only
    DecisionFirstCrawl                 // no prior hash, proceed to extraction
)

// Compare returns the change decision given the new hash and the prior hash
// (empty string if no prior).
func Compare(newHash, priorHash string) Decision {
    if priorHash == "" {
        return DecisionFirstCrawl
    }
    if newHash == priorHash {
        return DecisionUnchanged
    }
    return DecisionChanged
}

package extractor

import (
    "encoding/json"
    "fmt"
    "strings"

    "github.com/jedafe/japa/internal/intelligence/extractor/schemas"
)

// FieldExtraction is the per-field {value, confidence, evidence} triple.
type FieldExtraction struct {
    Value      any     `json:"value"`
    Confidence float64 `json:"confidence"`
    Evidence   *string `json:"evidence"`
}

// Extraction is the full LLM output — a map of field name to FieldExtraction.
type Extraction map[string]FieldExtraction

// ValidationError describes a validation failure.
type ValidationError struct {
    Field   string
    Message string
}

// Validate checks an LLM extraction against the entity schema.
// Returns the cleaned extraction (hallucinated fields reset to null) and
// any validation errors.
func Validate(ext Extraction, schema schemas.EntitySchema) (Extraction, []ValidationError) {
    var errs []ValidationError
    cleaned := make(Extraction, len(schema.Fields))

    for _, spec := range schema.Fields {
        field, ok := ext[spec.Name]
        if !ok {
            cleaned[spec.Name] = FieldExtraction{Value: nil, Confidence: 0, Evidence: nil}
            if spec.Required {
                errs = append(errs, ValidationError{spec.Name, "required field missing"})
            }
            continue
        }

        // Hallucination guard: non-null value MUST have non-empty evidence.
        if field.Value != nil {
            if field.Evidence == nil || strings.TrimSpace(*field.Evidence) == "" {
                errs = append(errs, ValidationError{spec.Name, "non-null value without evidence — treated as hallucination, reset to null"})
                cleaned[spec.Name] = FieldExtraction{Value: nil, Confidence: 0, Evidence: nil}
                continue
            }
        } else {
            // value is null → evidence MUST be null (consistency)
            if field.Evidence != nil && strings.TrimSpace(*field.Evidence) != "" {
                errs = append(errs, ValidationError{spec.Name, "null value with non-empty evidence — inconsistent, evidence cleared"})
                field.Evidence = nil
            }
        }

        // Confidence sanity
        if field.Confidence < 0 || field.Confidence > 1 {
            errs = append(errs, ValidationError{spec.Name, fmt.Sprintf("confidence %f out of [0,1]", field.Confidence)})
            field.Confidence = 0
        }

        // TODO: type coercion per spec.Type (date, country_array, enum, numeric)
        // For now, accept as-is — type coercion is implemented in a follow-up step.

        cleaned[spec.Name] = field
    }

    return cleaned, errs
}

// ParseExtraction parses raw LLM JSON output into an Extraction.
func ParseExtraction(raw []byte) (Extraction, error) {
    var ext Extraction
    if err := json.Unmarshal(raw, &ext); err != nil {
        return nil, fmt.Errorf("extractor: parse: %w", err)
    }
    return ext, nil
}
```

package services

import "time"

// FreshnessScore computes a 0-100 freshness score based on age.
// 100 = today, 90 = this week, 70 = this month, 40 = older, 0 = stale (>90 days).
func FreshnessScore(verifiedAt time.Time, now time.Time) int {
    age := now.Sub(verifiedAt)
    switch {
    case age <= 24*time.Hour:
        return 100
    case age <= 7*24*time.Hour:
        return 90
    case age <= 30*24*time.Hour:
        return 70
    case age <= 90*24*time.Hour:
        return 40
    default:
        return 0
    }
}
