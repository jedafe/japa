# Flutter Mobile App v2.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the full v2.1 JapaConnect Flutter mobile app (`apps/mobile`) and shared Dart package (`packages/japaconnect_core`) as a thin API client for iOS and Android.

**Architecture:** One shared Dart package (`packages/japaconnect_core`) holds the OpenAPI-generated typed API client, auth, models, and shared widgets. `apps/mobile` consumes it through self-contained feature modules, uses `flutter_riverpod` for state, `go_router` for navigation, and a bottom-nav app shell.

**Tech Stack:** Flutter 3.47.0+ / Dart 3.13.0+, `flutter_riverpod` 3.4.2, `go_router` 17.5.0, `flutter_secure_storage` 11.0.0, `firebase_messaging` 16.5.0, `firebase_core` 4.13.0, `web_socket_channel` 3.0.3, `cached_network_image` 3.4.1, `fl_chart` 1.2.0, `openapi_generator` 7.0.0, `freezed` 3.2.5 / `json_serializable` 6.14.1.

## Global Constraints

These apply to every task. Each task's requirements implicitly include this section.

- **Flutter/Dart only** — no `bun`, `npm`, `pnpm`, or `yarn` for Flutter work.
- **State management** — `flutter_riverpod` (`Notifier`, `AsyncNotifier`, `FutureProvider`). No `setState` soup in feature screens.
- **Navigation** — `go_router` with deep links and shell routing.
- **HTTP** — typed `japaconnect_core` API client only. No raw `http` or `dio` in `apps/mobile/lib/features/`.
- **Auth** — device-scoped JWT; access token in memory; refresh token and device ID in `flutter_secure_storage`; `X-Device-Id` header on every request.
- **No hardcoded data** — every list, option, and user-owned value comes from `/api/v1` (Rule 16).
- **No AI attribution** — no "Generated by AI" / "Co-Authored-By" in any code, commit, or doc (Rule 17).
- **All commits to `main`** unless explicitly told otherwise.
- **API-Readiness Gate** — before any feature module, list and verify every consumed endpoint in `conventions/api-routes-catalog.md` or by probing the backend. If any are missing, stop.
- **Feature module isolation** — each module owns `screens/`, `providers/`, `services/`, `widgets/` and may not import from sibling `features/` modules.
- **Tests** — `flutter analyze` and `flutter test` before finishing each task.
- **Models** — code examples use `Map<String, dynamic>` for clarity. In the implementation, substitute the generated OpenAPI model classes produced by `openapi_generator`.

**Pattern files (for a feature `X`):**

- `apps/mobile/lib/features/x/services/x_service.dart`
- `apps/mobile/lib/features/x/providers/x_provider.dart`
- `apps/mobile/lib/features/x/screens/x_list_screen.dart` and/or `x_detail_screen.dart`
- `apps/mobile/lib/features/x/widgets/x_card.dart` (if needed)

**Pattern service:**

```dart
import 'package:japaconnect_core/japaconnect_core.dart';

class XService {
  final JcApiClient _client;
  XService(this._client);

  Future<List<XModel>> listX(...) async {
    final response = await _client.getX(...);
    return (response as List).map((j) => XModel.fromJson(j)).toList();
  }

  Future<XModel> getXDetail(...) async {
    final response = await _client.getXDetail(...);
    return XModel.fromJson(response);
```

```dart
import 'package:flutter/foundation.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:japaconnect_core/auth/token_store.dart';
import 'package:japaconnect_core/auth/device_id.dart';
import 'package:japaconnect_core/auth/auth_state.dart';
import 'api_error.dart';
import 'generated/api_client.dart';

final tokenStoreProvider = Provider<TokenStore>((ref) => TokenStore());

final jcApiClientProvider = Provider<JcApiClient>((ref) {
  final tokenStore = ref.watch(tokenStoreProvider);
  final deviceId = ref.watch(deviceIdProvider);
  final baseUrl = const String.fromEnvironment('JC_API_BASE_URL', defaultValue: 'http://localhost:8080/api/v1');
  final wsUrl = const String.fromEnvironment(
    'JC_WS_URL',
    defaultValue: '',
  );
  return JcApiClient(
    baseUrl: baseUrl,
    wsUrl: wsUrl,
    tokenStore: tokenStore,
    deviceId: deviceId,
    onUnauthenticated: () => ref.read(isAuthenticatedProvider.notifier).state = false,
  );
});

class JcApiClient {
  final String baseUrl;
  final String wsUrl;
  final TokenStore tokenStore;
  final DeviceId deviceId;
  final VoidCallback? onUnauthenticated;
  String? _accessToken;
  late final GeneratedApiClient _inner;

  JcApiClient({
    required this.baseUrl,
    this.wsUrl = '',
    required this.tokenStore,
    required this.deviceId,
    this.onUnauthenticated,
  }) {
    _inner = GeneratedApiClient(basePath: baseUrl);
  }

  String get effectiveWsUrl {
    if (wsUrl.isNotEmpty) return wsUrl;
    final base = Uri.parse(baseUrl).resolve('/').toString();
    return base
        .replaceFirst('https://', 'wss://')
        .replaceFirst('http://', 'ws://')
        .replaceFirst(RegExp(r'/?$'), '/ws');
  }

  String? get accessToken => _accessToken;

  void setAccessToken(String token) => _accessToken = token;
  void clearAccessToken() => _accessToken = null;

  Future<Map<String, String>> _buildHeaders({bool includeAuth = true}) async {
    final headers = <String, String>{
      'X-Device-Id': await deviceId.value,
    };
    if (includeAuth && _accessToken != null) headers['Authorization'] = 'Bearer $_accessToken';
    return headers;
  }

  Future<T> get<T>(String path, {Map<String, dynamic>? query, required T Function(dynamic) parse}) async {
    return _request<T>('GET', path, query: query, parse: parse);
  }

  Future<T> post<T>(String path, {Map<String, dynamic>? body, required T Function(dynamic) parse}) async {
    return _request<T>('POST', path, body: body, parse: parse);
  }

  Future<T> patch<T>(String path, {Map<String, dynamic>? body, required T Function(dynamic) parse}) async {
    return _request<T>('PATCH', path, body: body, parse: parse);
  }

  Future<T> put<T>(String path, {Map<String, dynamic>? body, required T Function(dynamic) parse}) async {
    return _request<T>('PUT', path, body: body, parse: parse);
  }

  Future<void> delete(String path) async {
    await _request<void>('DELETE', path, parse: (_) {});
  }

  Future<T> _request<T>(String method, String path, {
    Map<String, dynamic>? query,
    Map<String, dynamic>? body,
    required T Function(dynamic) parse,
    bool includeAuth = true,
  }) async {
    final response = await _inner.client.request(
      method,
      '$baseUrl$path',
      headers: await _buildHeaders(includeAuth: includeAuth),
      query: query,
      body: body,
    );

    if (response.statusCode == 401) {
      if (!includeAuth) {
        onUnauthenticated?.call();
        throw JcApiError(code: 'unauthenticated', message: 'Session expired', status: 401);
      }
      final refreshed = await _refresh();
      if (!refreshed) {
        onUnauthenticated?.call();
        throw JcApiError(code: 'unauthenticated', message: 'Session expired', status: 401);
      }
      return _request<T>(method, path, query: query, body: body, parse: parse);
    }

    if (response.statusCode >= 400) {
      throw JcApiError.fromJson(response.body as Map<String, dynamic>);
    }

    return parse(response.body);
  }

  Future<bool> refresh() => _refresh();

  Future<bool> _refresh() async {
    final refreshToken = await tokenStore.readRefreshToken();
    if (refreshToken == null) {
      clearAccessToken();
      return false;
    }
    try {
      final data = await _request<Map<String, dynamic>>(
        'POST',
        '/auth/refresh',
        body: {'refresh_token': refreshToken},
        parse: (json) => json as Map<String, dynamic>,
        includeAuth: false,
      );
      _accessToken = data['access_token'] as String;
      await tokenStore.writeRefreshToken(data['refresh_token'] as String);
      return true;
    } catch (_) {
      onUnauthenticated?.call();
      await logout();
      return false;
    }
  }

  Future<void> logout() async {
    try {
      await post<void>('/auth/logout', parse: (_) {});
    } catch (_) {}
    clearAccessToken();
    await tokenStore.deleteRefreshToken();
  }
}
```

```dart
const _secureStorage = FlutterSecureStorage();

final deviceIdProvider = Provider<DeviceId>((ref) => DeviceId());

class DeviceId {
  String? _value;

  String? get valueOrNull => _value;

  Future<String> get value async {
    if (_value != null) return _value!;
    var stored = await _secureStorage.read(key: 'device_id');
    if (stored == null) {
      stored = const Uuid().v4();
      await _secureStorage.write(key: 'device_id', value: stored);
    }
    _value = stored;
    return _value!;
  }
}
```

```dart
  final JcApiClient client;

  AuthService({required this.client});

  String? get accessToken => client.accessToken;

  Future<void> login(
    String username,
    String password, {
    void Function()? onAuthenticated,
  }) async {
    final result = await client.post<Map<String, dynamic>>(
      '/auth/login',
      body: {'username': username, 'password': password},
      parse: (json) => json as Map<String, dynamic>,
    );
    final challengeToken = result['challenge_token'] as String?;
    final accessToken = result['access_token'] as String?;
    if (challengeToken != null && accessToken == null) {
      throw JcApiError(code: 'totp_required', message: challengeToken, status: 401);
    }
    await _persist(result);
    onAuthenticated?.call();
  }

  Future<void> register(
    String username,
    String email,
    String password, {
    void Function()? onAuthenticated,
  }) async {
    final result = await client.post<Map<String, dynamic>>(
      '/auth/register',
      body: {'username': username, 'email': email, 'password': password},
      parse: (json) => json as Map<String, dynamic>,
    );
    await _persist(result);
    onAuthenticated?.call();
  }

  Future<void> verifyTOTP(
    String challengeToken,
    String code, {
    void Function()? onAuthenticated,
  }) async {
    final result = await client.post<Map<String, dynamic>>(
      '/auth/totp/verify-challenge',
      body: {'challenge_token': challengeToken, 'code': code},
      parse: (json) => json as Map<String, dynamic>,
    );
    await _persist(result);
    onAuthenticated?.call();
  }

  Future<bool> refresh() async => client.refresh();

  Future<void> logout() async {
    try {
      final manager = PushTokenManager(client: client, deviceId: client.deviceId);
      await manager.deregister();
    } catch (_) {}
    await client.logout();
  }

  Future<void> _persist(Map<String, dynamic> result) async {
    client.setAccessToken(result['access_token'] as String);
    await client.tokenStore.writeRefreshToken(result['refresh_token'] as String);
  }
}
```

```dart
import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:japaconnect_core/japaconnect_core.dart';

final authFormProvider = NotifierProvider<AuthFormNotifier, AuthFormState>(() => AuthFormNotifier());

class AuthFormState {
  final bool isLoading;
  final String? error;
  final String? challengeToken;

  const AuthFormState({this.isLoading = false, this.error, this.challengeToken});

  AuthFormState copyWith({bool? isLoading, String? error, String? challengeToken}) {
    return AuthFormState(
      isLoading: isLoading ?? this.isLoading,
      error: error ?? this.error,
      challengeToken: challengeToken ?? this.challengeToken,
    );
  }
}

class AuthFormNotifier extends Notifier<AuthFormState> {
  @override
  AuthFormState build() => const AuthFormState();

  AuthService get _auth => ref.read(authServiceProvider);

  void _setAuthenticated() {
    ref.read(isAuthenticatedProvider.notifier).state = true;
  }

  Future<void> login(String username, String password) async {
    state = state.copyWith(isLoading: true, error: null);
    try {
      await _auth.login(username, password, onAuthenticated: _setAuthenticated);
      state = state.copyWith(isLoading: false);
    } on JcApiError catch (e) {
      if (e.code == 'totp_required') {
        state = state.copyWith(isLoading: false, challengeToken: e.message);
      } else {
        ref.read(isAuthenticatedProvider.notifier).state = false;
        state = state.copyWith(isLoading: false, error: e.message);
      }
    }
  }

  Future<void> register(String username, String email, String password) async {
    state = state.copyWith(isLoading: true, error: null);
    try {
      await _auth.register(username, email, password, onAuthenticated: _setAuthenticated);
      state = state.copyWith(isLoading: false);
    } on JcApiError catch (e) {
      ref.read(isAuthenticatedProvider.notifier).state = false;
      state = state.copyWith(isLoading: false, error: e.message);
    }
  }

  Future<void> verifyTOTP(String code) async {
    state = state.copyWith(isLoading: true, error: null);
    try {
      final token = state.challengeToken;
      if (token == null) {
        state = state.copyWith(isLoading: false, error: 'No challenge token');
        return;
      }
      await _auth.verifyTOTP(token, code, onAuthenticated: _setAuthenticated);
      state = state.copyWith(isLoading: false);
    } on JcApiError catch (e) {
      ref.read(isAuthenticatedProvider.notifier).state = false;
      state = state.copyWith(isLoading: false, error: e.message);
    }
  }
}
```

```dart
/// Listens to [realtimeEventsProvider] and invalidates [feedProvider] on
/// `feed_update` events. Keep this provider alive by watching it in a long-lived
/// widget (e.g., the app shell or [FeedScreen]) so the listener survives rebuilds.
final feedRealtimeSyncProvider = Provider<void>((ref) {
  ref.listen(realtimeEventsProvider, (previous, next) {
    next.whenData((event) {
      if (event['type'] == 'feed_update') {
        ref.invalidate(feedProvider);
      }
    });
  });
```

```dart
final conversationsProvider = FutureProvider.autoDispose<List<Map<String, dynamic>>>((ref) async {
  final service = ref.watch(socialServiceProvider);
  return service.listConversations();

final conversationMessagesProvider = FutureProvider.autoDispose.family<List<Map<String, dynamic>>, String>((ref, id) async {
  final service = ref.watch(socialServiceProvider);
  return service.getConversationMessages(id);
});

/// Listens to [realtimeEventsProvider] and [pushServiceProvider.foregroundMessages]
/// and invalidates the relevant providers for `notification` and `dm` events.
/// For `dm` events, also invalidates the specific
/// `conversationMessagesProvider(conversationId)` when the payload includes a
/// `conversation_id`. The stream subscriptions are cancelled when this provider
/// is disposed.
final socialRealtimeSyncProvider = Provider<void>((ref) {
  ref.listen(realtimeEventsProvider, (previous, next) {
    next.whenData((event) {
      final type = event['type'] as String?;
      switch (type) {
        case 'notification':
          ref.invalidate(notificationsProvider);
          break;
        case 'dm':
          ref.invalidate(conversationsProvider);
          final conversationId = event['conversation_id'] as String?;
          if (conversationId != null) {
            ref.invalidate(conversationMessagesProvider(conversationId));
          }
          break;
      }
    });
  });

  final pushSub = ref.watch(pushServiceProvider).foregroundMessages.listen((_) {
    ref.invalidate(notificationsProvider);
  });
  ref.onDispose(pushSub.cancel);
});
```

```dart
import 'package:flutter/foundation.dart';
import 'package:firebase_messaging/firebase_messaging.dart';
import 'package:japaconnect_core/auth/device_id.dart';
import 'package:japaconnect_core/api/client.dart';
import 'package:japaconnect_core/api/api_error.dart';

class PushTokenManager {
  final JcApiClient client;
  final DeviceId deviceId;

  PushTokenManager({required this.client, required this.deviceId});

  bool get _isMobile => defaultTargetPlatform == TargetPlatform.android || defaultTargetPlatform == TargetPlatform.iOS;

  Future<void> register(String platform) async {
    if (!_isMobile) return;
    final token = await FirebaseMessaging.instance.getToken();
    if (token == null) return;
    final id = await deviceId.value;
    final body = {'device_id': id, 'platform': platform, 'token': token};
    try {
      await client.post<void>('/me/devices', body: body, parse: (_) {});
      return;
    } on JcApiError catch (e) {
      if (e.status != 404) rethrow;
    }
    await client.post<void>(
      '/me/push-tokens',
      body: {'token': token, 'platform': platform, 'device_id': id},
      parse: (_) {},
    );
  }

  Future<void> deregister() async {
    if (!_isMobile) return;
    final id = await deviceId.value;
    try {
      await client.delete('/me/devices/$id');
      return;
    } on JcApiError catch (e) {
      if (e.status != 404) rethrow;
    }
    await client.delete('/me/push-tokens/$id');
  }

  Future<void> listenAndRefresh() async {
    if (!_isMobile) return;
    FirebaseMessaging.instance.onTokenRefresh.listen((token) async {
      if (client.accessToken == null) return;
      final id = await deviceId.value;
      final platform = defaultTargetPlatform == TargetPlatform.iOS ? 'ios' : 'android';
      final body = {'device_id': id, 'platform': platform, 'token': token};
      try {
        await client.post<void>('/me/devices', body: body, parse: (_) {});
        return;
      } on JcApiError catch (e) {
        if (e.status != 404) rethrow;
      }
      await client.post<void>(
        '/me/push-tokens',
        body: {'token': token, 'platform': platform, 'device_id': id},
        parse: (_) {},
      );
    });
  }
}
```

```dart
class PushService {
  final JcApiClient client;
  final DeviceId deviceId;
  final _foregroundController = StreamController<RemoteMessage>.broadcast();
  var _listeningToForeground = false;
  var _listeningToTokenRefresh = false;

  PushService({required this.client, required this.deviceId});

  Stream<RemoteMessage> get foregroundMessages => _foregroundController.stream;

  Future<void> initialize() async {
    if (defaultTargetPlatform != TargetPlatform.android && defaultTargetPlatform != TargetPlatform.iOS) return;
    await FirebaseMessaging.instance.requestPermission();
    if (!_listeningToForeground) {
      FirebaseMessaging.onMessage.listen((message) => _foregroundController.add(message));
      _listeningToForeground = true;
    }
    if (client.accessToken == null) return;
    final manager = PushTokenManager(client: client, deviceId: deviceId);
    await manager.register(defaultTargetPlatform == TargetPlatform.iOS ? 'ios' : 'android');
    if (!_listeningToTokenRefresh) {
      manager.listenAndRefresh();
      _listeningToTokenRefresh = true;
    }
  }

  Future<void> deregister() async {
    if (defaultTargetPlatform != TargetPlatform.android && defaultTargetPlatform != TargetPlatform.iOS) return;
    final manager = PushTokenManager(client: client, deviceId: deviceId);
    await manager.deregister();
  }
}
```

```dart
import 'dart:async';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:japaconnect_core/api/client.dart';
import 'socket_client.dart';

final socketServiceProvider = Provider<SocketService>((ref) {
  final client = ref.watch(jcApiClientProvider);
  return SocketService(client: client);
});

final realtimeEventsProvider = StreamProvider<Map<String, dynamic>>((ref) {
  final socket = ref.watch(socketServiceProvider);
  return socket.events;
});

class SocketService {
  final JcApiClient client;
  final _eventController = StreamController<Map<String, dynamic>>.broadcast();
  SocketClient? _socket;
  Timer? _reconnectTimer;

  SocketService({required this.client});

  Stream<Map<String, dynamic>> get events => _eventController.stream;

  Future<void> connect() async {
    if (client.accessToken == null || _socket != null) return;
    final ticket = await client.post<Map<String, dynamic>>(
      '/auth/ws-ticket',
      parse: (json) => json as Map<String, dynamic>,
    );
    _socket = SocketClient(url: client.effectiveWsUrl);
    _socket!.connect(ticket['token'] as String);
    _socket!.events.listen(
      (event) => _eventController.add(event as Map<String, dynamic>),
      onError: (_) => _onConnectionLost(),
      onDone: _onConnectionLost,
    );
  }

  void _onConnectionLost() {
    _socket = null;
    _scheduleReconnect();
  }

  void _scheduleReconnect() {
    _reconnectTimer?.cancel();
    _reconnectTimer = Timer(const Duration(seconds: 5), connect);
  }

  void disconnect() {
    _reconnectTimer?.cancel();
    _socket?.disconnect();
    _socket = null;
  }
}
```

```dart
class RealtimeInitializer extends ConsumerStatefulWidget {

class _RealtimeInitializerState extends ConsumerState<RealtimeInitializer> {
  ProviderSubscription<bool>? _sub;

  @override
  void initState() {
    super.initState();
    _sub = ref.listen<bool>(isAuthenticatedProvider, (prev, next) {
      final socket = ref.read(socketServiceProvider);
      if (next) {
        socket.connect();
      } else {
        socket.disconnect();
      }
    });
  }

  @override
  void dispose() {
    _sub?.close();
    ref.read(socketServiceProvider).disconnect();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) => widget.child;
}
```

Wrap `JapaConnectApp` with `RealtimeInitializer` after the `PushInitializer` in `main.dart`.

**Feature-isolation note:** `RealtimeInitializer` only starts and stops the global socket connection. Feature providers must subscribe to `realtimeEventsProvider` internally and invalidate themselves when an event of their own concern is received. Example implementations: `feedRealtimeSyncProvider` (Task 7) and `socialRealtimeSyncProvider` (Task 12). Each sync provider uses `ref.listen` on `realtimeEventsProvider`, invalidates the relevant `FutureProvider` (e.g., `feedProvider`, `notificationsProvider`, `conversationsProvider`), and the stream subscription is cancelled when the provider is disposed.
