# AI BYOK Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let frontend users attach their own AI provider API keys (BYOK) so chat/agent turns run on the user's key — cutting platform cost — with admin-curated provider allowlist and affiliate "get a key" links for revenue.

**Architecture:** Two new tables (`ai_byok_providers` admin-curated storefront, `user_ai_keys` encrypted user credentials). The unified chat endpoint accepts `byok_key_id`; the agent loop dispatches to an ephemeral `Provider` built from the decrypted key instead of the platform `Dispatcher` — never falling back to platform providers. Picker groups: Platform (filtered by `ai.chat.allowed_models`) + Your keys.

**Spec:** `docs/superpowers/specs/2026-10-19-ai-byok-design.md`

**Tech Stack:** Go (chi, pgx/v5, `internal/crypto` AES encryption), PostgreSQL migrations (golang-migrate up/down pairs), SvelteKit 2 + Svelte 5 runes (`apps/main` SSR, `apps/control` SPA), `@japaconnect/ai-panel` package.

## Global Constraints

- Rule 16: no hardcoded data in frontend — everything from API.
- Rule 17: no AI attribution in commits, comments, or docs.
- Rule 18: frontend tooling is `bun`/`bunx` — never npm/npx.
- Feature toggles live in `feature_flags` via `features.Registry` — never a `system_settings *.enabled` key.
- API errors use `errpkg.WriteError(w, status, "snake_case_code", "message")`.
- New tables get up/down migration pairs; next number is **000890**.
- Plaintext user keys NEVER leave the backend — responses carry `api_key_masked` only.
- `provider_type` for BYOK is restricted: `openai`, `anthropic`, `groq`, `perplexity` only (DB CHECK).
- Permission node seeding pattern: `INSERT INTO permissions` + `INSERT INTO role_permissions SELECT ur.id, p.id FROM user_roles ur, permissions p WHERE ur.slug = ...`.
- Verification: `go test ./internal/ai/... ./internal/control/...`, `go build ./...`, `bunx svelte-check` / `bun run check` in the touched app.

Follow `providers.go` conventions exactly (dual pools, `scan*` row seam, `json.Unmarshal` for models jsonb, dynamic SET-clause update like `UpdateProvider`). Key function:

```go
// ResolveProvider loads the caller's key, checks the BYOK provider is still
// enabled and the model is in its catalog, decrypts, and constructs an
// ephemeral Provider. It never touches the platform Dispatcher — a BYOK
// turn can never fall back to platform keys.
func (s *UserAIKeyStore) ResolveProvider(ctx context.Context, userID, keyID pgtype.UUID, model string) (Provider, error) {
    k, err := s.GetForUser(ctx, userID, keyID)
    if err != nil {
        return nil, ErrAIKeyNotFound
    }
    if !k.Provider.Enabled {
        return nil, ErrByokProviderDisabled
    }
    if model != "" && !k.Provider.HasModel(model) {
        return nil, ErrByokModelNotAllowed
    }
    plain, err := s.decryptedKey(ctx, keyID)
    if err != nil {
        return nil, err
    }
    cfg := ProviderConfig{
        Name:         k.Provider.DisplayName,
        ProviderType: k.Provider.ProviderType,
        Model:        model,
    }
    return NewProviderFromConfig(cfg, plain)
}
```

`ListEnabled` joins nothing; `ListForUser` LEFT JOINs `ai_byok_providers` so each key carries its provider block. `GetForUser` is `WHERE id = $1 AND user_id = $2` (ownership in SQL → foreign id is 404).

```go
// HTTPStatusError wraps a provider's non-2xx response so callers can
// classify failures (e.g. mark a BYOK key invalid on 401/403) without
// string-parsing. Error() keeps the legacy message format.
type HTTPStatusError struct {
    Provider string
    Status   int
    Body     string
}

func (e *HTTPStatusError) Error() string {
    return fmt.Sprintf("%s: API error (status %d): %s", e.Provider, e.Status, truncate(e.Body, 500))
}

// IsProviderAuthError reports whether err (possibly wrapped) is a provider
// 401/403 rejection — the only failures that mark a BYOK key invalid.
func IsProviderAuthError(err error) bool {
    var he *HTTPStatusError
    if errors.As(err, &he) {
        return he.Status == http.StatusUnauthorized || he.Status == http.StatusForbidden
    }
    return false
}
```

Extract the per-provider body of `ChatWithToolsStream` (stream.go:70-140) into:

```go
// chatWithToolsStreamOn runs the stream→single-shot degrade dance against
// one provider — the BYOK path where cross-provider fallback is forbidden.
func chatWithToolsStreamOn(ctx context.Context, p Provider, req ChatWithToolsRequest, sink DeltaSink) (ChatWithToolsResponse, error) {
    streamer, ok := p.(ChatStreamer)
    if !ok {
        resp, err := p.ChatWithTools(ctx, req)
        if err != nil { return ChatWithToolsResponse{}, err }
        resp.ProviderName = p.Name()
        return resp, nil
    }
    emitted := false
    resp, err := streamer.ChatStream(ctx, req, func(d string) {
        if d == "" { return }
        emitted = true
        if sink != nil { sink(d) }
    })
    switch {
    case err == nil:
        resp.ProviderName = p.Name()
        return resp, nil
    case emitted:
```
