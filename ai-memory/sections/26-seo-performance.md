## Metadata Resolution

Generic metadata resolver keyed off `content_type`, populating OG tags on every publicly shareable entity; `noindex` on private/admin surfaces. Canonical URL emitted from `contents.canonical_url` if set, otherwise self-referencing.

```go
func ResolveMetadata(content *Content) PageMetadata {
  canonical := content.CanonicalURL
  if canonical == "" {
    canonical = buildSelfURL(content)
  }
  og := OGMeta{
    Title:       coalesce(content.OGTitle, content.Title),
    Description: coalesce(content.OGDescription, excerpt(content.Body, 160)),
    Image:       coalesce(content.OGImage, defaultBannerURL()),
    Type:        ogType(content.ContentType),
    Canonical:   canonical,
  }
  if content.Visibility == "private" {
    return PageMetadata{Robots: "noindex,nofollow", OG: og}
  }
  return PageMetadata{Robots: "index,follow", OG: og}
}
```

## Dynamic OG Image Generation

A Go handler at `/api/v1/og-image` generates platform-branded OG images on demand using `golang.org/x/image` + a pre-rendered template. Images are cached in Valkey (key: `jc:og:{content_id}`, TTL 24h) and served with `Cache-Control: public, max-age=86400`.

```go
func OGImageHandler(w http.ResponseWriter, r *http.Request) {
  contentID := r.URL.Query().Get("id")
  cacheKey := "jc:og:" + contentID
  if cached, err := valkey.GetBytes(r.Context(), cacheKey); err == nil {
    w.Header().Set("Content-Type", "image/png")
    w.Header().Set("Cache-Control", "public, max-age=86400")
    w.Write(cached)
    return
  }
  content, _ := getContent(r.Context(), contentID)
  img := renderOGImage(content) // 1200×630, platform template
  buf := new(bytes.Buffer)
  png.Encode(buf, img)
  valkey.Set(r.Context(), cacheKey, buf.Bytes(), 24*time.Hour)
  w.Header().Set("Content-Type", "image/png")
  w.Write(buf.Bytes())
}
```

## Sitemap (Chunked, Quality-Gated)

Chunked sitemap-index (50k URLs per file). Generated by `sitemap_generate` Asynq task (low tier, daily + triggered on significant content events). Quality gates per Section 43's `IsSpaceIndexable()` and `IsContentIndexable()`.

UserGroup-level gate: admin sets `allow_search_indexing` per UserGroup. New/unverified members' posts excluded from sitemap and Meilisearch until they meet a reputation threshold (configurable). Inspiration from dev.to.

Image sitemaps included for content with featured images. Regenerated alongside main sitemap.

## robots.txt

Dynamically generated per Section 43 (admin-configurable via known_bots registry). Cached in Valkey TTL 24h.

## llms.txt / llms-full.txt

Per llmstxt.org spec. Generated by `maintenance:regenerate_llms_txt` (low tier, every hour). See Section 43.

## Core Web Vitals

Targeted at Google's "Good" thresholds. Supported by:
- Redis/Valkey caching of rendered content
- SSR (SvelteKit adapter-node on main site)
- imgproxy for all image transformations (no layout-shifting from unoptimized images)
- Font subsetting (Inter Variable, JetBrains Mono Variable — only the Unicode ranges needed)
- Lighthouse CI gate in GitHub Actions catches CWV regressions

## Cloudflare Integration

If Cloudflare is configured (API token in system_settings):
- Cache purge on content publish/update: tag-based purge using `CF-Cache-Tag` headers
- DDoS protection (Cloudflare handles at edge, no Go-level changes needed)
- Bot management supplement: known bots (Section 43) that aren't blocked at robots.txt level are reported via Cloudflare's bot management if available

```go
func PurgeCloudflareCache(ctx context.Context, tags []string) error {
  cfToken := getSystemSetting("integrations.cloudflare.api_token")
  cfZone  := getSystemSetting("integrations.cloudflare.zone_id")
  if cfToken == "" || cfZone == "" { return nil } // Cloudflare not configured, skip
  return cloudflareClient.PurgeCacheTags(ctx, cfZone, cfToken, tags)
}
```
