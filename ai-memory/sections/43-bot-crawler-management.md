# Section 43 — Bot & Crawler Management

**Status:** ✅ Locked

## robots.txt (Admin-Configurable)

robots.txt is not a static file — it's generated dynamically from admin settings and cached in Valkey (TTL 24h). Admin configures it in Admin Panel → Settings → SEO → Bot Management.

## Known Bot Registry (Seeded, Admin-Editable)

```sql
CREATE TABLE known_bots (
  id                 uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id          uuid NOT NULL REFERENCES tenants(id),
  name               text NOT NULL,
  user_agent_pattern text NOT NULL,
  bot_type           text NOT NULL,
  -- 'search_engine'|'ai_llm'|'social'|'monitoring'|'scraper'|'unknown'
  policy             text NOT NULL DEFAULT 'allow',
  -- 'allow'|'block'|'limit'
  is_system          boolean NOT NULL DEFAULT false,
  updated_at         timestamptz NOT NULL DEFAULT now()
);
```

Pre-seeded: Googlebot, Bingbot (search → allow), GPTBot, ClaudeBot, PerplexityBot (ai_llm → allow, admin may block), Twitterbot, LinkedInBot (social → allow), AhrefsBot, SemrushBot (scraper → limit).

## Dynamic robots.txt

```go
func RobotsHandler(w http.ResponseWriter, r *http.Request) {
  cached, _ := valkey.Get(r.Context(), "jc:robots_txt")
  if cached != "" {
    w.Header().Set("Content-Type", "text/plain")
    w.Write([]byte(cached))
    return
  }
  rules := buildRobotsFromBotRegistry(r.Context())
  valkey.Set(r.Context(), "jc:robots_txt", rules, 24*time.Hour)
  w.Header().Set("Content-Type", "text/plain")
  w.Write([]byte(rules))
}
```

## Sitemap Quality Gates

```go
func IsSpaceIndexable(s *Space) bool {
  minMembers := getSystemSettingInt("seo.sitemap.space_min_members", 1)
  minPosts   := getSystemSettingInt("seo.sitemap.space_min_posts", 1)
  return s.MemberCount >= minMembers && s.PostCount >= minPosts
}

func IsContentIndexable(c *Content, authorGroup *UserGroup) bool {
  if c.Status != "published" || c.Visibility == "private" { return false }
  minWords := getSystemSettingInt("seo.sitemap.content_min_words", 100)
  if wordCount(c.Body) < minWords { return false }
  return authorGroup.AllowSearchIndexing
}
```

UserGroup-level indexing gate: admin can mark a UserGroup's content as non-indexable (e.g. new/unverified members' posts are not added to sitemap or Meilisearch until they meet a minimum reputation threshold — configurable per group, inspiration from dev.to).
